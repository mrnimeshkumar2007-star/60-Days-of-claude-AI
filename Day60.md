# ❓ Questions & Answers

### Q1. Why is a README important?

**Answer:**
A README helps users and developers understand the project, installation process, features, technologies used, and contribution guidelines.

---

### Q2. What does production-ready mean?

**Answer:**
It means the application has been tested, optimized, documented, secured, and is ready for real users.

---

### Q3. Why should developers maintain GitHub repositories?

**Answer:**
A well-maintained repository demonstrates professionalism, improves collaboration, and helps recruiters evaluate technical skills.

---

### Q4. Why is documentation important?

**Answer:**
Documentation makes projects easier to understand, maintain, and extend by future contributors.

---

### Q5. What is the purpose of versioning (e.g., v1.0.0)?

**Answer:**
Versioning tracks project progress, communicates release milestones, and helps manage future updates systematically.
