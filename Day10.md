# Day 10 -Build Your Personal Portfolio Website

## Objective

The objective of this project was to design and develop a modern, responsive personal portfolio website that showcases my skills, projects, achievements, and professional profile in a visually appealing and recruiter-friendly format. The goal was to strengthen my frontend development skills while building a professional online presence.

---

## About the Project

This project is a single-page personal portfolio website developed using HTML, Tailwind CSS, and JavaScript. It includes sections such as Hero, About Me, Skills, Projects, Achievements, and Contact. The website features dark/light mode, smooth scrolling, typing animations, responsive design, and interactive UI components.

---

## Prompt Used

I used an AI-assisted prompt to generate the portfolio structure:

> "Build a complete, modern, single-file personal portfolio website using HTML, Tailwind CSS (CDN), and vanilla JavaScript. Include Hero section, About Me, Skills with animated bars, Projects cards, Achievements, Contact form, Dark/Light mode toggle, Mobile responsiveness, Smooth scroll animations, Active navigation highlighting, SEO meta tags, and recruiter-friendly content."

The AI then customized the portfolio using my resume details including:

* Name
* Education
* Skills
* Certifications
* Project Experience
* Contact Information

## Interview Questions & Answers

### Q1. Why did you build this portfolio website?

**Answer:**
I wanted to create a professional online presence that showcases my skills, projects, certifications, and achievements while improving my frontend development skills.

---

### Q2. Why did you choose Tailwind CSS?

**Answer:**
Tailwind CSS allows rapid UI development through utility classes. It helps create responsive and modern designs without writing large custom CSS files.

---

### Q3. What JavaScript functionalities did you implement?

**Answer:**
I implemented:

* Dark/Light Mode Toggle
* Typing Animation
* Scroll Reveal Animations
* Active Navigation Highlighting
* Smooth Scrolling Effects

---

### Q4. How is the website responsive?

**Answer:**
The website uses Tailwind CSS responsive utility classes and flexible grid layouts that automatically adjust across mobile, tablet, and desktop devices.
