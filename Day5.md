## Example Difference

### Prompt A Output

* Learn fundamentals
* Practice exercises
* Build a small project
* Review weekly
* Complete a final project

This works for almost any topic but doesn't account for who the learner is.

### Prompt B Output

If the context is:

* Student
* Python basics
* Goal: Become an AI Engineer
* 2 hours/day
* Beginner
* Prefers project-based learning

The roadmap might include:

**Week 1**

* Python revision
* NumPy basics
* Pandas fundamentals

**Week 2**

* Data preprocessing
* Visualization
* Exploratory analysis project

**Week 3**

* Machine Learning basics
* Train first model

**Week 4**

* End-to-end AI project
* GitHub portfolio setup
* LinkedIn showcase

This roadmap is directly connected to the learner's goal.

## Key Insight

**Prompt A answers:**
"What should someone generally do over 30 days?"

**Prompt B answers:**
"What should *this specific person* do over 30 days to reach *their specific goal*?"

That's why Prompt B usually produces a more valuable and effective roadmap. Context transforms a generic learning plan into a personalized action plan.
