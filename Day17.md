# Day 17 - Build an AI Vehicle Cost & Fuel Analysis Dashboard

# 🎯 Objective

The objective of this project was to use **AI-powered Prompt Engineering, Data Analytics, and Frontend Development** to transform raw vehicle and fuel data into an interactive, business-friendly dashboard.

The goal was to:

* Analyze vehicle operating costs.
* Compare different fuel options (Petrol, E85, CNG, EV).
* Measure environmental impact through CO₂ emissions.
* Visualize insights using charts and KPI cards.
* Generate a responsive HTML dashboard automatically using AI.
* Demonstrate how structured prompts can automate data analysis and dashboard creation.

---

# 📖 Learn About the Project

This project combines multiple disciplines:

### 🚗 Vehicle Analytics

Understanding fuel costs, maintenance expenses, and vehicle efficiency.

### 📊 Data Analytics

Calculating:

* Cost per KM
* Maintenance per KM
* CO₂ emissions per KM
* Fuel comparisons
* Monthly operating expenses

### 🤖 Prompt Engineering

Designing detailed prompts that guide AI to:

* Perform calculations
* Generate insights
* Create visualizations
* Build frontend code

### 💻 Frontend Development

Building a:

* Responsive Dashboard
* KPI Cards
* SVG Charts
* Glassmorphism UI
* Mobile-Friendly Layout

# 💡 Key Learnings

## 1. Prompt Quality Drives Output Quality

A detailed prompt produces significantly better results than a simple request.

### Example

Instead of:

> Create a dashboard.

Use:

> Calculate metrics, generate charts, compare fuels, and build a responsive HTML dashboard.

---

## 2. Data Is More Valuable Than Assumptions

AI can only generate accurate analytics when provided with quality data.

---

## 3. Visualization Improves Understanding

Charts communicate trends faster than tables.

Examples:

* Cost Comparison Chart
* CO₂ Distribution Chart
* Age Analysis Chart
* E85 Score Gauge

## 4. AI Can Accelerate Development

AI reduced time spent on:

* Calculations

* Visualization Logic
* HTML/CSS Structure

---

## 5. Analytics Supports Better Decisions

Data-driven decisions are more reliable than intuition alone.

## ❓ Question & Answer

### Q1. What was the purpose of this dashboard?

**Answer:**
To analyze vehicle operating costs, fuel efficiency, maintenance expenses, and environmental impact in a visual format.

---

### Q2. Why compare Petrol, E85, CNG, and EV?

**Answer:**
Each fuel type has different trade-offs in cost, emissions, maintenance, and convenience.

---

### Q3. What role did AI play?

**Answer:**
AI automated:

* Calculations
* Data analysis
* Dashboard design
* Code generation
* Insight creation

---

### Q4. What is the E85 Paradox?

**Answer:**
Although E85 fuel may be cheaper at the pump, reduced mileage can impact actual running costs.

The dashboard evaluates:

* Pump Savings
* Running Penalty
* Break-even Price

---

### Q5. Why use KPI Cards?

**Answer:**
KPI cards quickly highlight the most important metrics without requiring users to read large datasets.

---

### Q6. What is the biggest takeaway?

**Answer:**
Prompt Engineering combined with Data Analytics can transform raw information into actionable business intelligence.
