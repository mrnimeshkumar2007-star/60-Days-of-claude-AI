### Claude Model Selection

**Haiku**

* Fastest responses
* Best for quick questions and summaries

**Sonnet**

* Best balance of speed and intelligence
* Ideal for coding, learning, projects, and career preparation

**Opus**

* Deep reasoning and advanced analysis

## Prompt Used

### Learning Prompt

> Explain [TOPIC] in simple terms as if I'm a beginner. Include examples, key points, and a short summary at the end.

### Coding Prompt

> Write a [LANGUAGE] program for [PROBLEM]. Include comments, explain the logic, and analyze the time complexity.

### Resume Prompt

> Review my resume and optimize it for ATS. Improve bullet points, suggest skills to add, and make it more impactful for [ROLE].

### Interview Prompt

> Prepare me for a [ROLE] interview. Ask questions one by one with explanations and feedback.

### AI/ML Prompt

> Explain [AI/ML CONCEPT] with real-world examples and a simple Python implementation.

## Biggest Mistakes I Should Avoid

### ❌ Using Opus for everything

It is often unnecessary for student-level tasks and can slow your workflow.

### ❌ Using Max effort on simple questions

Max effort is best reserved for genuinely complex tasks.

### ❌ Asking vague questions

Instead of:

> "Teach me Python"

Ask:

> "Teach me Python functions with 5 beginner examples and exercises."

### ❌ Treating Claude like Google

Give context and goals for better responses.

### ❌ Copy-pasting generated code without understanding it

Use Claude as a tutor, not just a code generator.

### ❌ Not creating reusable prompts

Save prompts for:

* Resume optimization
* DSA practice
* Interview preparation
* AI learning
